# Link Acquisition — Thu hút backlink quy mô

## 1. Purpose / Mục đích
Link Acquisition là **góc nhìn growth của Off-page SEO**: thay vì làm thủ công từng link, build hệ thống thu hút link tự nhiên + outreach scale. Bao gồm linkable asset, partnership, embed widget, statistic publishing, và automation. Trong khi Off-page Link Building tập trung tactic level, Link Acquisition tập trung **engine + system level**.

## 2. Core Concepts / Khái niệm cốt lõi

- **Linkable asset moat**: tài sản tự kéo link (free tool, dataset, template gallery).
- **Link velocity sustainable**: tốc độ link increase đều, không spike.
- **Link compounding**: bài có 50 RD attract thêm link organic.
- **Referral cascade**: 1 link mạnh dẫn tới 5–10 link nhỏ.
- **Co-citation / Co-occurrence**: brand mention cùng top brand → tin signal.
- **Brand attraction > outreach push**: long-term equity.
- **Acquisition channel mix**: Editorial (highest), PR, Resource page, Niche edit, Tool embed, Listicle inclusion, Statistic citation, Interview, Affiliate partnership, Award listing.

## 3. When to use
- Khi đã có content foundation tốt.
- Khi muốn scale RD growth ≥ 30/tháng.
- Khi quarterly link goal cần system thay vì tactic.
- Khi outreach manual đã saturate.

## 4. Workflow Link Acquisition System

### Bước 1. Set growth goal
- Total RD year-end target.
- Per-quarter milestone.
- DR distribution target (bao nhiêu link DR ≥ 50, ≥ 70).
- Cost per link cap.
- Channel mix expected.

### Bước 2. Build asset portfolio (3–5 asset/year)

**Asset types**:
- **Original research / data study**: industry survey, scraped data analysis, internal data report.
- **Free tool / calculator**: skill Tools Content.
- **Definitive guide / pillar**: skill Pillar Pages.
- **Template gallery**: 50+ template / template hub.
- **Interactive content**: quiz, simulator, calculator.
- **Glossary / encyclopedia**: 100+ term.
- **Dataset download**: CSV / API access.
- **Embeddable widget**: chart, badge, calculator user copy embed.
- **Award / list**: "Top X in {industry} 2025" (hosted by you).
- **Free certification / course**.
- **Free design / open-source resource**.

Mỗi asset chuẩn bị link-bait từ Day 1: shareable URL, quote-able stat, embed code, infographic export.

### Bước 3. Acquisition channel matrix

**A. Passive (asset-driven)**:
- Tool embed → user link tự.
- Statistic citation passive.
- Listicle inclusion (tự nhiên khi tool nổi).

**B. Active outreach (skill Outreach + Link Building)**:
- Resource page.
- Broken link replacement.
- Niche edit.
- Guest post.
- Listicle pitch.

**C. PR-driven (skill Digital PR)**:
- Survey / data report.
- Newsjacking.
- Embargo Tier 1.
- HARO / Qwoted reactive.

**D. Brand-driven**:
- Conference / event.
- Podcast guesting.
- Partnership co-marketing.
- Open-source contribute.
- Award nominate.

**E. Programmatic / scale**:
- Affiliate program with link.
- Customer logo wall (case study link).
- Job listing on site (recruiter cite).
- Free tool widget embed.
- Badge: "Featured on" / "X% off via badge".

### Bước 4. Pipeline build
Build dedicated team / role:
- Asset team: product/eng/design/data build asset.
- Outreach team: do contact + sequence.
- PR specialist: pitch journalist.
- Partnership manager: BD-style relationship.

Even nhỏ, set role clearly.

### Bước 5. Velocity + sustainability
- Plan link acquisition 12 tháng theo cohort.
- Spike (Digital PR week) + steady-state (outreach, embed) mix.
- Avoid all-in 1 channel.

### Bước 6. Quality control + disavow
- Reject low-quality offer.
- Quarterly toxic link audit.
- Disavow conservative.
- Track win rate per channel.

(Xem Off-page Link Building.)

### Bước 7. Co-citation tactics
- Có brand mình mention cùng top brand trong cùng content.
- Pitch listicle "Top X tools" với mình + Salesforce + HubSpot.
- "X integrations" page có mình.
- "Best in {category}" award page.

### Bước 8. Embed widget engine
Cho tool / widget có:
- Embed code copyable với 1 click.
- Default attribution link.
- Customizable theme / size.
- Referral parameter.
- Track embed → backlink scrape weekly.

### Bước 9. Automation
- Mention scrape: tool Ahrefs Alert, Brand24 → unlinked → outreach convert.
- Wikipedia mention scrape.
- Statistic cite tool: track ai cite stat của mình.
- Email sequence: Mailshake / Smartlead / Lemlist warm.
- CRM: BuzzStream, Pitchbox, Respona.

### Bước 10. Compound effect tracking
- Top 10% asset contribute X% link?
- Asset evergreen attract link sau 1 năm?
- Link velocity steady or decline?
- Compare DR distribution growth.

## 5. Template Link Acquisition Plan

```
## Link Acquisition Plan — Year {X}

### Goal
- +500 RD year-end (current: 200, target: 700)
- DR mix: ≥ 50 link DR ≥ 60 / ≥ 100 link DR ≥ 30
- Cost cap: $50/link average

### Asset portfolio
- Q1: Survey + data report (1500 respondent, ngách X)
- Q2: Free calculator tool
- Q3: Definitive pillar guide
- Q4: Statistic roundup 2025

### Channel allocation
- 40% Active outreach
- 25% PR (Digital PR + HARO)
- 20% Passive (asset embed, statistic cite)
- 10% Brand (podcast, conference)
- 5% Programmatic (affiliate, badge)

### Team
- Outreach lead + 2 specialist
- PR specialist (contractor)
- Partnership manager
- Asset producer (rotating)

### Tooling
- Ahrefs / Semrush
- Pitchbox / BuzzStream
- Smartlead
- HARO / Qwoted
- Brand24

### Cadence
- Weekly: 100 outreach, 1 podcast pitch
- Monthly: HARO 20 reply
- Quarterly: 1 Digital PR campaign
- 2x/year: 1 major asset launch

### KPI
- RD growth, win rate, cost per link, DR distribution
```

## 6. KPI đo lường
- RD growth / quarter.
- New link from DR ≥ 50.
- Win rate per channel.
- Cost-per-link.
- Per-asset link contribution.
- Compound rate (link/quarter cho asset > 1 năm tuổi).
- # unique anchor variation.
- Spam disavow rate.

## 8. Common mistakes
- Build asset không có distribution plan → link không đến.
- Outreach scale mà không personalization → blacklist.
- All-in 1 channel → fragile.
- Velocity spike rồi dừng → unnatural pattern.
- Ignore co-citation strategy.
- Embed widget nhưng không track outbound link → không biết ROI.
- Customer logo wall không link 2 chiều.
- Asset 1 lần publish, không refresh → link decay.
- Bỏ qua brand-driven (podcast, event) — chỉ làm digital outreach.
- Cost cap quá thấp → quality drop.
- Quên track DR distribution → toàn link DR thấp.
- Disavow aggressive → mất link tốt.
- Kéo link vào homepage thay vì pillar / money page.
- AI auto-generate outreach copy không edit → spammy.
- Tin số RD = success — quality + relevance > quantity.
- Bỏ qua nofollow link Reddit/Quora — vẫn có giá trị traffic + co-citation.

---
**Đầu ra**: link acquisition engine có asset moat + multi-channel + automation + tracking → RD growth steady với cost-per-link tối ưu.
