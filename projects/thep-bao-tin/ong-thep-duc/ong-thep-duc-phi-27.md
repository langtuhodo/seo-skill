# Ống thép đúc phi 27

- Đường kính danh nghĩa: DN20
- Đường kính ngoài: 26,7 mm
- Độ dày: 1.6, 2.1, 2.8, 3.9, 5.5, 7.8mm….

- Tiêu chuẩn sản xuất: Tiêu chuẩn API 5L, Tiêu chuẩn ASTM A106/ A53/ A312,….
