# Tech Stack — SEO Skills Library

## File Format
- **Markdown (.md)** — tất cả content đều là Markdown
- **UTF-8 encoding** — hỗ trợ tiếng Việt

## Structure
- `SKILL.md` — 8-section template chuẩn cho mỗi skill
- `knowledge/*.md` — 16 knowledge notes với trigger keywords
- `playbooks/*.md` — 7 end-to-end workflows

## Conventions
- Tiếng Việt làm chính
- Thuật ngữ SEO giữ nguyên tiếng Anh (search intent, canonical, hreflang, schema, EEAT)
- Mỗi skill ~1000+ từ

## Tools Referenced
- **Keyword Research**: Ahrefs, Semrush, Google Keyword Planner, AlsoAsked
- **Technical SEO**: Screaming Frog, Sitebulb, GSC, Lighthouse
- **Content**: Surfer, Frase, Clearscope
- **Analytics**: GA4, GSC, Looker Studio, BigQuery
- **Link Building**: Pitchbox, BuzzStream, Hunter.io, HARO
- **AI SEO**: ChatGPT, Claude, Perplexity, Gemini, Google NLP API
