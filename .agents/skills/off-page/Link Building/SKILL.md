# Link Building — Xây dựng backlink

## 1. Purpose / Mục đích
Backlink vẫn là **một trong 3 ranking factor mạnh nhất**. Không có backlink, content tốt cũng khó vượt qua đối thủ DR cao. Skill này định nghĩa cách kiếm link **chất lượng, an toàn (white-hat), và scale được** — không phải PBN, không spam comment, không link farm.

## 2. Core Concepts / Khái niệm cốt lõi

- **Backlink (referring link)**: link từ domain khác trỏ về site mình.
- **Referring Domain (RD)**: số domain unique link tới site (đếm domain quan trọng hơn đếm link).
- **DR / DA / Authority Score**: proxy metric độ mạnh domain (Ahrefs / Moz / Semrush). KHÔNG phải Google metric.
- **PageRank flow**: link truyền authority. Link từ DR cao + topic relevant > nhiều link DR thấp.
- **Anchor text**: text của link. Pattern bình thường: 60% branded, 20% naked URL, 15% generic, 5% exact match keyword.
- **Dofollow vs Nofollow / UGC / Sponsored**: Google chính thức coi nofollow là "hint" — vẫn có thể truyền link equity. Vẫn ưu tiên dofollow.
- **Link velocity**: tốc độ kiếm link. Tăng đột biến = red flag.
- **Toxic link**: link từ site spam, có thể disavow (xem skill liên quan).
- **Link types** quan trọng:
  - Editorial (best, hard to get)
  - Resource page
  - Guest post
  - Niche edit / link insertion
  - Digital PR / HARO
  - Broken link replacement
  - Listicle inclusion
  - Statistic citation
  - Tool / Free resource (passive)
  - Brand mention conversion (unlinked → linked)

## 3. When to use
- Liên tục — link building là long-term play, không phải sprint.
- Sau khi content foundation đã tốt (đừng link build cho thin content).
- Khi muốn boost specific page (money page, pillar).
- Khi gap so với đối thủ về RD lớn.
- Khi launch asset mới (tool, study, guide).

## 4. Workflow link building

### Bước 1. Set goal
- # RD / quý.
- Target DR distribution (vd: 5 link DR ≥ 50, 15 link DR 30–50, 30 link DR < 30).
- Target page (money page, pillar — không phải scatter random).
- Anchor distribution.
- Budget.

### Bước 2. Asset preparation (linkable asset)
Backlink đến với:
- **Original research / data report**.
- **Free tool / calculator**.
- **Definitive guide / pillar**.
- **Statistic roundup** (top X stats về Y).
- **Template / template gallery**.
- **Infographic + embed code**.
- **Interactive content** (quiz, simulation).
- **Industry survey result**.

→ Chuẩn bị 2–3 asset/quarter làm "magnet".

### Bước 3. Strategy stack (combo)

**A. Resource page link building**:
- Tìm: `"keyword" inurl:resources`, `"keyword" inurl:links`, `"useful tools"`.
- Pitch: ngắn gọn, value-first, fit với resource page hiện tại.
- Win rate: 5–15%.

**B. Guest post**: xem skill Guest Posting.

**C. Broken link building**:
- Tìm: site có ngách phù hợp → check broken outbound link (Ahrefs Broken backlinks).
- Pitch: "Tôi thấy bạn link tới X nhưng đã 404, có alternative trên site mình".
- Win rate: 10–20%.

**D. Digital PR**: xem skill Digital PR.

**E. HARO / SourceBottle / Qwoted / journalists requests**:
- Subscribe → reply quickly với expert quote.
- Win rate: 5–10%.

**F. Niche edit / link insertion**:
- Pitch site cùng ngách: "Nội dung tôi mới publish có thể bổ sung vào bài X của bạn".
- Cần có nội dung deserve (data, ví dụ, template).
- Win rate: 10–20%. KHÔNG mua link.

**G. Listicle outreach**:
- Tìm: `"top X tools for Y"`, `"best X for Y"`.
- Pitch: tool/guide của mình deserve inclusion.

**H. Unlinked brand mention conversion**: xem skill Brand Mentions.

**I. Statistic citation**:
- Publish 1 trang "X statistics 2025" với original survey.
- Outreach + passive: writer cite số → link tới trang stats.

**J. Skyscraper technique**:
- Tìm bài đang có nhiều backlink → viết bài tốt hơn 10x.
- Outreach tới site đang link bài cũ.
- Hiệu quả giảm sau 2020 nếu không có angle thực sự khác.

**K. Podcast guesting**:
- Pitch làm guest podcast ngách → host link tới site mình trong show notes.
- Bonus: brand authority + voice.

**L. Tool / chrome extension / plugin**:
- Build product nhỏ free → user tự cite.

### Bước 4. Outreach (xem skill Outreach)
Templated framework: Subject ngắn + opener cá nhân + value + ask 1 dòng.

### Bước 5. Tracking
- Sheet: target site, contact, outreach date, status, link earned, anchor, DR, dofollow.
- CRM dedicated: Pitchbox, BuzzStream, Respona.
- Đo win rate per channel để optimize allocation.

### Bước 6. Quality gate
KHÔNG chấp nhận link từ:
- Site DR < 5 không có traffic thật.
- Site irrelevant (tài chính, casino, gambling unless natural).
- Site có nhiều outbound link spam (audit "outgoing links" của domain).
- PBN, link farm.
- Site không có About / Editorial / contact.
- Site index < 50 trang.

### Bước 7. Disavow strategy
- Quarterly: review GSC Links + Ahrefs/Semrush backlink → identify toxic.
- Disavow chỉ khi (a) link rõ ràng spam, (b) lượng nhiều ảnh hưởng, (c) đã tried remove qua webmaster.
- Disavow file submit GSC.
- Conservative: Google đã ít cần disavow vì algorithm tự devalue.

## 6. KPI đo lường
- # RD / quý.
- DR / Authority distribution của RD mới.
- # link tới money page, pillar.
- Anchor distribution healthy (≤ 5% exact match).
- Win rate per channel.
- Cost per link (USD).
- Time-to-first-link cho asset mới.
- Position uplift của target page sau link.

## 8. Common mistakes
- Mua link rẻ trên Fiverr → vào hệ thống PBN → penalty.
- Spam outreach template → blacklist domain mình.
- Anchor over-optimization (50% exact match) → unnatural.
- Link tới homepage tất cả → không boost được money page.
- Chạy theo volume thay vì quality → tốn budget không kết quả.
- Không có asset → outreach nói về cái gì?
- Bỏ qua relationship building dài hạn (chỉ outreach 1 chiều).
- Disavow bừa bãi → mất link tốt.
- Quên track win rate per channel → không tối ưu allocation.
- Build link cho trang thin content → conversion 0.
- Không kết hợp PR / brand → link không bền vững khi algorithm thay đổi.
- Bỏ qua nofollow link từ Reddit, Wikipedia, social — vẫn có giá trị traffic + ranking signal indirect.
