# Knowledge Note — Off-page SEO

**Trigger**: khi user nhắc "backlink", "link building", "guest post", "digital PR", "brand mention", "outreach", "DR / DA", "link velocity", "anchor text", "linkable asset".

## Mục đích

Build authority external thông qua backlink + brand mention + PR + relationship. Topical Map giúp biết trang nào ưu tiên nhận backlink (Core Section/pillar) và tạo linkable asset ở Outer Section.

## Khái niệm cốt lõi

### Link Building — 10 loại link
1. Editorial (được cite tự nhiên)
2. Resource page
3. Niche edit (thêm link vào bài existing)
4. HARO / Qwoted / Featured
5. Broken link replacement
6. Listicle inclusion
7. Statistic citation
8. Tool/calculator link
9. Unlinked mention conversion
10. Guest post

### Anchor Distribution chuẩn
- 60% branded / URL / generic
- 20% partial match
- 15% related/LSI
- 5% exact match

### Linkable Asset Strategy
- Xây asset ở Outer Section: nghiên cứu, thống kê, checklist, hướng dẫn dài, tool miễn phí
- Ưu tiên đẩy link về: pillar page / landing trong Core Section
- Dùng internal link: phân phối sức mạnh từ asset Outer → Core

### Tiêu chí backlink tốt
- Cùng hoặc gần chủ đề với Central Entity
- Trang đặt link có traffic + uy tín
- Anchor text tự nhiên, thể hiện bối cảnh
- Không spam từ khóa trong anchor

### Guest Posting
- White-hat pitch: 3 ideas + opener cá nhân
- Relationship 6+ tháng (không one-shot)
- Chọn site cùng niche, có traffic thật

### Digital PR
- Newsworthy hook: survey, data, geo ranking, newsjacking
- Tiered media list: Tier 1 (mainstream) → Tier 2 (industry) → Tier 3 (niche)
- Embargo strategy cho Tier 1

### Brand Mentions
- Monitor + triage: positive/neutral/negative
- Convert unlinked → linked (pitch nhẹ)
- Crisis management khi sentiment negative

### Outreach
- 4-phần email: opener (cá nhân), bridge (context), value (what's in it for them), ask (CTA)
- 5-email sequence: day 0, 3, 7, 14, 30
- Warm-up: SPF/DKIM/DMARC setup trước khi send

## Workflow — Link campaign

1. Define link goal (RD target, DR mix, cost cap, channel mix)
2. Asset chuẩn bị (data, tool, pillar, statistic, infographic)
3. Prospect list (Ahrefs Content Explorer, Semrush, BuzzStream)
4. Personalize + sequence (Smartlead / Mailshake / Pitchbox)
5. HARO + Qwoted parallel
6. Digital PR campaign 1/quý + Tier 1 embargo
7. Brand monitor (Brand24 / Mention) → unlinked convert
8. Track + report (RD, win rate, cost-per-link, DR distribution)

## Khi nào dùng

- Quarterly link goal
- Sau publish asset mới (pillar, tool, research)
- Monthly brand mention sweep
- Khi competitor có link gap mình nên catch up

## Common pitfall

- Link spam (PBN, exact match anchor, low DR < 5)
- Outreach template không personalize → blacklist
- Volume thay vì quality → Google devalue
- Spike velocity rồi dừng → unnatural pattern
- Bỏ qua nofollow Reddit/Quora — vẫn có giá trị traffic + brand
- Disavow aggressive → mất link tốt
- Link tới homepage thay vì pillar / money page
- Brand mention không track → bỏ lỡ unlinked conversion
- Tool content không backlink campaign launch → asset chết
- Tin số RD = rank — quality + relevance > quantity
- Linkable asset ở Outer nhưng không internal link về Core → authority không flow
