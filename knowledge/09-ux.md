# Knowledge Note — UX (cho SEO)

**Trigger**: khi user nhắc "UX", "page speed UX", "mobile optimization", "responsive", "A/B test SEO", "conversion funnel", "bounce rate cao", "scannability", "accessibility".

## Mục đích

UX ảnh hưởng SEO indirect nhưng mạnh: bounce, dwell, pogo-sticking, conversion, accessibility. Site technical + content tốt nhưng UX kém → vẫn thua.

## Khái niệm cốt lõi

### Page Speed UX (Perception)
- Perception > raw speed: skeleton screen, progressive disclosure, optimistic UI
- Loading state: < 1s → spinner, > 1s → skeleton
- Network-aware: giảm asset cho slow connection
- Khác với Technical Site Speed: đây là UX perception, không phải CWV metric

### Mobile Optimization
- Mobile-first index: Google crawl mobile version trước
- Viewport meta đúng
- Tap target ≥ 48px
- Font ≥ 16px body (tránh Safari auto-zoom)
- No horizontal scroll
- No intrusive interstitial (Google penalty)
- Real device test ≥ 5 device (không chỉ Chrome DevTools)

### UX Design cho SEO
- F/Z-pattern reading: đặt content quan trọng theo eye-tracking pattern
- Scannability: H2 mỗi 200-300 từ, bullet, TL;DR box
- Visual hierarchy: size, color, spacing guide attention
- Accessibility: contrast ≥ 4.5:1, alt text, keyboard navigation, ARIA labels
- Lighthouse a11y score > 95

### A/B Testing (SEO-safe)
- Hypothesis + sample size + guardrail + ≥ 14 days
- SEO-safe rules:
  - Same URL (không redirect split)
  - Không cloak Googlebot (serve khác user vs bot = vi phạm)
  - Server-side preferred over client-side
- Statistical significance trước khi ship

### Conversion Funnels
- TOFU/MOFU/BOFU mapping theo content type
- GA4 funnel exploration: identify drop-off
- Pareto: fix top drop-off step trước
- Stage-based content: mỗi stage cần content + CTA khác nhau

## Workflow — UX-SEO audit

1. CWV mobile field check (LCP/INP/CLS)
2. Heatmap + recording (Hotjar/Clarity)
3. GSC bounce + engagement per page
4. UX scannability review (TL;DR, H2 cadence, bullet, FAQ)
5. Mobile real device test ≥ 5 device
6. Accessibility audit (axe, Lighthouse a11y > 95)
7. Funnel mapping → drop-off identify
8. A/B test hypothesis cho top drop-off step

## Khi nào dùng

- Audit cluster underperform (rank top 5 nhưng bounce cao)
- Trước launch landing page / template mới
- Khi conversion drop trên mobile
- Khi accessibility audit needed

## Common pitfall

- Tối ưu lab speed bỏ qua perception
- Tap target < 48px mobile → mis-tap
- Font 12-14px → Safari auto-zoom + a11y fail
- A/B test cloak Googlebot serving khác → vi phạm
- Test < 14 ngày → noise, không statistical significance
- Bỏ qua mobile real device test
- Pop-up intrusive → Google penalty
- Accessibility bỏ qua → 15-20% audience excluded
- Funnel optimize TOFU only, bỏ qua BOFU drop-off
- Bỏ qua last-click vs assist attribution → SEO blog underrated
