# Knowledge Note — SEO Foundations

**Trigger**: khi bắt đầu dự án SEO mới, khi cần hiểu framework nền tảng, khi user nhắc "source context", "central entity", "topical map", "core section", "outer section", hoặc khi cần giải thích thuật ngữ SEO cơ bản.

## Mục đích

Định nghĩa các khái niệm nền tảng mà mọi hoạt động SEO đều xây dựng trên đó. Đây là "ngôn ngữ chung" — AI phải hiểu rõ trước khi thực thi bất kỳ task SEO nào.

## Khái niệm cốt lõi

### Glossary — Thuật ngữ nền

| Thuật ngữ | Định nghĩa |
|-----------|------------|
| **Source Context** | Ngữ cảnh nguồn của website: mục tiêu thương hiệu, cách kiếm tiền, nhóm khách hàng, cách muốn được nhận diện |
| **Central Entity** | Thực thể trung tâm mà toàn bộ nội dung website xoay quanh (ví dụ: Canada, Tiếng Anh cho trẻ em, Ống thép) |
| **Central Search Intent** | Ý định tìm kiếm trung tâm — câu hỏi/mục tiêu lớn nhất mà site sinh ra để phục vụ |
| **Core Section** | Phần nội dung quan trọng nhất, giao nhau giữa Source Context + Central Entity, trực tiếp phục vụ chuyển đổi |
| **Outer Section** | Phần nội dung mở rộng xoay quanh Central Entity, bổ sung kiến thức và xây topical authority |
| **Pillar Page** | Trang trụ cột bao quát chủ đề rộng, liên kết tới nhiều bài con (cluster) |
| **Topic Cluster** | Nhóm nội dung: 1 pillar + nhiều cluster page liên kết chặt bằng internal link |
| **Topical Map** | Sơ đồ hệ thống các core topic, supporting topic, subtopic — thể hiện cách site bao phủ toàn bộ lĩnh vực |
| **Search Intent** | Mục đích thực sự đằng sau truy vấn: Informational / Navigational / Commercial / Transactional |
| **Long-tail Keyword** | Cụm từ khóa dài, cụ thể, volume thấp, cạnh tranh thấp, gần hành vi mua |
| **Linkable Asset** | Nội dung giá trị cao (nghiên cứu, tool, template) dễ được website khác tạo backlink |
| **E-E-A-T** | Experience, Expertise, Authoritativeness, Trustworthiness — bộ tiêu chí đánh giá chất lượng nội dung |
| **Awareness Stage** | Mức độ nhận thức khách hàng: Unaware → Problem Aware → Solution Aware → Product Aware → Most Aware |

### Framework Topical Map

**Ba trụ cột nền:**

1. **Source Context** — trả lời: Bạn là ai? Tiếp cận ai? Kiếm tiền bằng cách nào? Muốn được nhận diện thế nào?
2. **Central Entity** — thực thể trung tâm xuất hiện xuyên suốt mọi nội dung
3. **Central Search Intent** — câu hỏi lớn nhất mà website trả lời

**Công thức:**
- Core Section = Source Context + Central Entity (gắn chuyển đổi)
- Outer Section = Central Entity + Central Search Intent (bổ trợ authority)

### Cấu trúc Topical Map đầy đủ

```
1. Source Context
2. Central Entity
3. Central Search Intent
4. Core Section (pillar page, landing — gắn chuyển đổi)
5. Outer Section (blog, resource, cluster bổ trợ)
6. Supporting topics + Subtopics dưới mỗi Core/Outer
```

### Các bước tạo Topical Map

1. Xác định Source Context (khung thương hiệu + mô hình kiếm tiền)
2. Xác định Central Entity
3. Xác định Central Search Intent
4. Liệt kê Core Section (chủ đề gắn chuyển đổi)
5. Liệt kê Outer Section (chủ đề bổ trợ kiến thức)
6. Dùng tool keyword để bẻ Core/Outer thành supporting topics → subtopics
7. Đánh nhãn: Core/Outer, Intent, Awareness Stage
8. Map từng topic vào kiểu page (pillar/landing/blog/resource) + internal link

### Kết nối Topical Map với Awareness Funnel

| Stage | Vị trí trong Topical Map | Loại content |
|-------|--------------------------|--------------|
| Unaware | Outer Section | Câu chuyện, insight, truyền cảm hứng |
| Problem Aware | Outer + Core | Giải thích vấn đề, hệ quả |
| Solution Aware | Outer nâng cao | So sánh giải pháp, checklist |
| Product Aware | Core Section | Landing, pillar dịch vụ/sản phẩm |
| Most Aware | Core Section | Case study, review, offer, FAQ bán hàng |

## Workflow — Khi bắt đầu dự án SEO mới

1. Xác định Source Context + Central Entity + Central Search Intent
2. Lập Topical Map: Core Section + Outer Section
3. Bẻ thành supporting topics + subtopics (dùng keyword tool)
4. Gán intent + awareness stage + business priority cho mỗi topic
5. Map vào kiểu page + URL structure
6. Thiết kế internal link map (hub → spoke)
7. Ưu tiên: Core Section trước → Outer Section sau
8. Lưu Topical Map dạng bảng (Topic, Core/Outer, Intent, Awareness, Volume, URL, Type)

## Khi nào dùng

- Bắt đầu bất kỳ dự án SEO nào — **bắt buộc đọc file này trước**
- Khi cần giải thích thuật ngữ SEO cho user
- Khi tạo topical map mới
- Khi cần xác định Core vs Outer Section
- Khi map content vào awareness funnel

## Tools

- Ahrefs / Semrush (keyword research, topic discovery)
- Google Search Console (real query data)
- AlsoAsked / AnswerThePublic (question mining)
- Notion / Google Sheets (lưu topical map)
- ChatGPT / Claude (brainstorm subtopics, classify intent)

## Common pitfall

- Không xác định Source Context → viết content lan man, không gắn business
- Central Entity quá rộng (ví dụ "Marketing") → không đủ depth để thắng
- Bỏ qua Outer Section → site chỉ có landing, không có authority
- Core Section quá nhiều → phân tán resource, không cluster nào đủ mạnh
- Topical Map chỉ dựa trên volume → bỏ qua business value + intent
- Không phân biệt Core vs Outer → internal link lộn xộn, không có conversion path
- Tạo Topical Map 1 lần rồi bỏ → cần audit quarterly
- Long-tail keyword không gắn vào cluster → bài rời rạc, không topical authority
